# Graduation Project Starter

Chào mừng bạn đến với **Graduation Project Starter**! Đây là một dự án mẫu (Proof of Concept) dành cho các bạn sinh viên IT đang bắt đầu làm đồ án tốt nghiệp. Dự án hướng dẫn từng bước từ việc thiết lập môi trường cho đến khi xây dựng hoàn chỉnh một ứng dụng Web Fullstack (Todo List) sử dụng React.js, Node.js, Express và PostgreSQL.

## Mục lục (Phases)

Dự án được chia thành 7 giai đoạn (phases) từ dễ đến khó:

1. [Phase 1: Setup Môi trường Phát triển và Database (Docker)](./01-DevTools-and-Docker/README.md)
2. [Phase 2: Khởi tạo React App và Quản lý Mã nguồn với Git](./02-React-Init-and-Git/README.md)
3. [Phase 3: Khởi tạo Backend với Node.js và Express.js](./03-Express-Setup/README.md)
4. [Phase 4: Kết nối Database và Tạo Bảng Dữ liệu](./04-Database-Connection/README.md)
5. [Phase 5: Xây dựng Giao diện React với Mock Data](./05-React-UI-TodoList/README.md)
6. [Phase 6: Xây dựng CRUD API cho Backend](./06-Backend-API/README.md)
7. [Phase 7: Ghép nối toàn hệ thống (Integration)](./07-Integration/README.md)

## Tech Stack
- **Frontend:** React.js (Vite)
- **Backend:** Node.js + Express.js
- **Database:** PostgreSQL + pgAdmin
- **Containerization:** Docker Compose

## Hướng dẫn bắt đầu

Hãy bắt đầu đọc hướng dẫn từ **[Phase 1](./01-DevTools-and-Docker/README.md)** và lần lượt thực hiện theo các bước chi tiết trong đó.

Chúc các bạn hoàn thành tốt đồ án!
